KNG ENTERTAINMENT UPDATE

This pack preserves the existing KNG Entertainment app and adds:

1. HOST AN EVENT
- Hungry Pool is replaced with Host an Event.
- Randomises empty 30-minute or 60-minute slots.
- Random pool contains the supplied Events Hub list, ending with KNG Boxing.
- The randomiser never selects Club 77 or Vanilla.
- The same event is never selected directly next to itself during one randomisation run.
- Existing events are never overwritten by the randomiser.
- Any slot can still be manually edited afterwards.

2. PLANNED / PROTECTED EVENTS
- Add one-time, daily, weekly or biweekly events.
- Planned slots are locked/protected from the randomiser.
- Existing pre-planned events are also safe because the randomiser only fills empty slots.

3. MANUAL EVENTS
- Club 77 and Vanilla can be added manually.
- Any supplied random event can also be added manually.
- Manual slots can optionally be protected.

4. PRIZES & COMMANDS
- Prize Win is now an on-page form rather than a pop-out.
- Three standard prize types are seeded:
  Dirty Money = dinheirosujo = 500000
  Dollars = dollars = 500000
  Event VIP = vipevento1 = 1
- In-game ID, prize type, amount and reason produce:
  !additem ID CODE AMOUNT Reason
- Command has a Copy button.
- Recorded prize wins have a Done checkbox for when the command has been given in Discord.
- Fixed the missing ops_prize_wins.reason database column error.

IMPORTANT:
Run KNG-ENTERTAINMENT-COMPLETE-MIGRATION.sql once in the Supabase SQL Editor before deploying this pack.
Do not delete the existing app assets.
