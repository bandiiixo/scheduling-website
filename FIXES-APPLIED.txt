KNG ENTERTAINMENT FULL FIX PACK - FIXES APPLIED

1. Staff-only event visibility now follows the requested hierarchy:
   MEMBER+ can see staff-only events/meetings; PUBLIC cannot.
   This is enforced in both the UI and Supabase RLS, not just hidden in the browser.

2. Staff meeting permissions fixed:
   Only MANAGER+ can create, edit or delete staff meetings.
   ADM can still manage normal Entertainment events.

3. Recurring event validation fixed:
   Repeat-until dates cannot be earlier than the first event/meeting date.

4. Hall of Fame fixed:
   Missing-table errors now show an in-page setup message instead of the old browser schema-cache alert.
   Winner photo position and zoom are saved and restored.
   Frame mode, colour, hue and intensity are stored.
   Added hex, RGB, hue and intensity controls.

5. Daily Goals fixed:
   Missing-table errors now show an in-page setup message instead of a browser alert.

6. Kick-off flow fixed:
   Kick-off reason defaults to Inactivity and blank reasons fall back to Inactivity.

7. Operations migration fixed:
   Adds/repairs all required operations tables and policies.
   Adds the missing Hall of Fame/Daily Goals schema.
   Adds persistent Hall of Fame photo positioning.
   Restricts staff-only event reads at database level.

8. Existing features were retained:
   Schedule calendar, Discord login, access hierarchy, recurring events, Party/Event/Battle Royale/Community Meeting presets, event completion, attendance/winners, leaderboards, Actions/Interactions roster, Tracker, Hungry Pool, Reductions, Helpers, Points, Prize Win, Commands/Copy, Security, Crashout protection, access requests, feedback/suggestions and Hall of Fame.

Prize system update (2026-10-30):
- Prize Win now uses a prize dropdown.
- Selecting a prize auto-fills its item code and amount.
- Prize commands now use !additem {ID} {code} {amount} Event Winner.
- Default prizes are Dirty Money (dinheirosujo, 500000), Dollars (dollars, 500000), and Event VIP (vipevento1, 1).
- Prize win records have a persistent Done checkbox for when the command has been copied, pasted, and given in Discord.
- Added completed/completed_at/completed_by fields to ops_prize_wins migration.
